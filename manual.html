videobeaux manual

How to use videobeaux, then every program mode and its settings.

Start Here

Welcome

videobeaux is a video playground. Drag program modes onto a canvas, connect them, press Run.

There are 168 program modes, grouped by what they do: glitch, trails, time, colour, tracking, layout, editing, captions and more. You can use one on its own or chain many, each feeding the next. Everything runs on your computer, offline, and your videos stay there.

New here? Do Install then Getting started. It takes about two minutes.

Install

videobeaux has everything built in. Nothing else to install.

Mac

You need a Mac with Apple silicon (M1 or later).

  1. Unzip the download and drag videobeaux into your Applications folder.
  2. Open it once from Applications. macOS says it can't be opened. Click Done.
  3. Open System Settings → Privacy & Security, scroll to the message about videobeaux and click Open Anyway.

This happens because the app isn't signed with an Apple certificate yet. It's safe to open, and it only asks once.

Windows

You need Windows 10 or 11 (64-bit) and about 4 GB of free space.

  1. Run the videobeaux Setup file you were sent.
  2. Windows says Windows protected your PC. Click More info, then Run anyway.
  3. Follow the installer. The default folder is fine.

First launch

A Setup screen checks the built-in video tools. Speech, voice and background-removal features download their models the first time you use them. Some are large.

Getting started

  1. Pick your video in the blue Input node (Browse…).
  2. Add programs: drag one from the list on the left onto the canvas, or double-click its name.
  3. Connect them: click the dot on the right edge of one box, then click the dot on the left edge of the next. A line follows your cursor in between. Chain it Input → programs → Output.
  4. In the orange Output node choose where to save (Save As…) and a format.
  5. Press ▶ Run Pipeline. Progress shows in the Signal Out bar at the bottom.

Quick first try: add a short video, search the program list for bad, drag Bad Predator onto the canvas, connect Input → Bad Predator → Output, and press Run.

Handy to know

  • Branching & extra videos — one output can feed several programs. Programs that need a second video (Layer Blend, Stack 2×…) show an extra dot, or drag + Input video onto the canvas for another source.
  • Numbers — drag the slider or type a value (the box can be emptied and retyped). The faint strip under a slider is a good starting range; the black tick is the default; ↺ resets. Some programs have Presets chips that fill several values at once. A slider marked curved (hover) is bent so its middle gives about half the visible effect; the box always shows the real value.
  • ✨ Tidy (⌘⇧L) arranges a messy canvas in connection order, or only the selected programs. It runs left → right or top → bottom, whichever suits the shape of the window (⌥⌘⇧L always goes top → bottom); ⌘Z undoes it. The toolbar shrinks with the window — ◂ hides it, ☰ Tools holds everything when it is narrow.
  • Did it work? — with the console folded, a chip shows ✓ Done, ✗ Failed at step n or ■ Cancelled; click it for the log. A notification appears if the window is in the background (🎨 Appearance → Notify when done).
  • Select several — ⌘/Ctrl-click or Shift-drag a box around them. ⌘G groups them so they move together; the caret on a group folds it into one card.
  • Copy & paste — ⌘C / ⌘V copy programs and the connections between them; ⌘D duplicates. ⌘Z undoes (also after Clear).
  • Clear empties the canvas after asking you to confirm. Save/Load Preset keeps a whole setup.
  • Fold a program — ▾ (or double-click its header) hides its settings; ▤ / ▦ in the bottom-left controls fold or unfold all. Folded state is saved in presets.
  • Look & lines — 🎨 Appearance changes the Look (Classic is the original), the colour of connection lines, and puts an image behind the canvas.
  • Visual editors — a ✎ button next to a field opens a purpose-built editor, such as Lagkage → Layout JSON (drop in images).

When something goes wrong

  • Read the Signal Out console — the last red line usually says what happened.
  • Nothing runs, or a red “not ready” message: open ⚙ Setup and press Repair.
  • Phone or HDR clips misbehaving: run Convert first (to mp4), then use that file.
  • AI features (speech, narration, background removal) need a one-time download in Setup → Local AI features; afterwards everything works offline.
  • A field says “max …”: that value is out of range and was set to the limit.
  • Found a bug? Click the ? icon in videobeaux to make a bug report, then send it on the feedback page.

Licenses & source

  • Videobeaux runs ffmpeg as a separate program. The bundled build is a GPL build (libx264 / libx265) that is never built with the non-redistributable --enable-nonfree option.
  • The exact source code of that ffmpeg and every library in it is published alongside each release of the build; the licence summary ships in the app's LICENSES folder.
  • You can use your own ffmpeg instead (Setup). AI models you download (speech, narration, background removal) keep their own licences.
